# MGB Institute Website

This is the source code for the official **Microbial Genomics and Biodegradation (MGB)** organization website.

## 🚀 Built With
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (Cinematic Animations)

## 📂 Content Management
- **People:** Manage profiles in `content/people/`
- **Publications:** Add BibTeX/Markdown in `content/publications/`
- **Research:** Update themes in `content/research/`

## 🛠️ Development
```bash
cd website
npm install
npm run dev
```

## 🌐 Deployment
This website is automatically deployed to GitHub Pages via **GitHub Actions** whenever you push to the `main` branch.
